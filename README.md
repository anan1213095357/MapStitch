# MapStitch 🗺️

一个专为 2D 游戏（特别是像素风/仙侠世界）设计的 4K 大地图无缝拼接与资产编辑器。

彻底告别繁琐的 PS 切图与手动对齐！MapStitch 运行在纯 Web 端，支持智能底色识别（不限纯黑）、多边形建筑掏空/缝合、物理掩码绘制，并可一键导出适配 Godot 4.x 的绝对坐标 JSON 与独立透明 PNG 切片，为您打通从 AI 绘图到游戏引擎的最后一步。

## ✨ 核心特性

- 🧩 **4K 无缝矩阵拼接**
  自动裁切相邻图像的重叠边缘，保证 4K 大地图区块间 100% 像素级对齐，无限延伸你的大世界画布。
- 🧠 **智能背景分离（任意纯色）**
  无需强制要求纯黑底！内置动态底色识别算法，自动分析并剥离纯色背景，精准提取建筑实体，自动完成边缘形态愈合与透空处理。
- ✂️ **多边形拓扑编辑**
  提供多边形拉线与矩形框选工具。闭合后可一键「掏空」建筑内部多余部分，或将多个细碎部件「缝合」为单一整体渲染层。
- 🎨 **多层掩码绘制**
  内置可视化画笔，无视网格边界自由绘制：**禁足区(红)**、**遮挡区(蓝)**、**前景层(黄)**。
- 📦 **Godot 原生工作流**
  一键导出 ZIP 数据包，内含所有独立透明 PNG 切片及带有全局绝对坐标的 `map_data.json`，直接拖入 Godot 即可读取。
- 💾 **本地离线缓存**
  基于纯前端架构与 IndexedDB，零服务端交互。所有项目资产毫秒级自动保存至浏览器本地，断网可用，极致流畅。

## 🚀 快速开始

本项目为纯前端单文件（Single-file）应用，无需安装任何 Node.js 依赖或构建工具。

1. 克隆或下载本仓库。
2. 在浏览器中直接双击打开 `index.html`。
3. 点击 **「上传 4K 背景」** 开始你的地图构建！

## 🕹️ 基本操作指南

- **漫游与缩放**：按住 `鼠标右键` 拖动画面，`鼠标滚轮` 无极缩放。
- **区块提取**：点击空白网格上的 `➕` 号，可自动生成并下载供 AI 局部重绘的边缘参考图。
- **建筑上传**：选中已有区块后，点击「上传纯色底建筑」，系统会自动识别底色并分离出建筑本体。
- **切割与合并**：切换至对应模式，在建筑上拉线或框选，闭合图形（多边形需点回起点）即刻生效。
- **撤销操作**：使用 `Ctrl + Z` 撤销刚刚画错的掩码或选区。

## 📂 导出数据结构 (Godot JSON)

导出的 ZIP 包中包含一个 `map_data.json`，格式如下，方便你在 Godot 中解析：

```json
{
  "map_version": "FINAL_PERFECT",
  "chunks": [
    {
      "chunk_id": "0_0",
      "grid_x": 0,
      "grid_y": 0,
      "background_path": "images/chunk_0_0_bg.jpg",
      "global_position": { "x": 0, "y": 0 },
      "buildings": [
        {
          "image_path": "images/chunk_0_0_building_0.png",
          "local_x": 120,
          "local_y": 340,
          "global_x": 120,
          "global_y": 340,
          "width": 512,
          "height": 512
        }
      ]
    }
  ],
  "global_polygons": {
    "col": [[[x,y], ...]], // 禁足碰撞区
    "occ": [[[x,y], ...]], // 遮挡区
    "fg":  [[[x,y], ...]]  // 前景层
  }
}
